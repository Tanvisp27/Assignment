Introduction to Web Development

Web development is the process of creating websites and web application that run on the Internet . It involves designing , coding and maintaining web pages using various technologies .

Objectives of Web Development
  • Understand basic structure of HTML document
  • Lear formatting and text alignment
  • Use lists , images and hyperlinks

Core Components of a Web Page

  1. HTML
    • Defines structure od the page
    • Uses tags like <html> , <head> , <body>
  2. CSS
    • Used for styling the web pages
    • Controls layout and colors
  3. JavaScript
    • Adds interactivity
    • Handles events and validations

Text Formatting Options

HTML allows text to be bold , italic , underlined , and even colored to make the content attractive .

Special Characters

Some Special Symbol used in HTML are :

  • Copyright symbol:©
  • Registered trademarket :®
  • Trademark :™
  • Less than sign : <
  • Greater than sign :>
  • Ampersand : &
